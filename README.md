# Autonomous Navigation and Learning-Based Control

ROS 2 autonomous navigation framework integrating map-based localization, custom A* planning, and learning-based trajectory tracking.

## Overview

- Nav2 AMCL and `map_server` localization
- Custom grid-based A* planner as a ROS 2 service
- Occupancy-grid collision checking
- TF management across `map`, `odom`, and `base_link`
- DDPG trajectory tracking implemented without external RL libraries
- PID benchmark and RViz visualization
